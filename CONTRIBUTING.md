# Contributing Guidelines

Thank you for contributing to this project! Please follow these guidelines to maintain a clean and professional workflow.

## Branching Strategy
* Create a dedicated feature or patch branch from `main` for any updates.
* Avoid making direct commits to the `main` branch.

## Commit Message Standard
* Use English-only metadata and descriptive commit messages following conventional standards:
  * `feat(scope): add new feature`
  * `fix(scope): resolve issue`
  * `docs(scope): update documentation`

## Pull Request Process
* Open a Pull Request targeting the `main` branch.
* Provide a clear description using pocket-manual markdown formatting.
* Ensure all checks pass and request a merge via the GitHub interface.
